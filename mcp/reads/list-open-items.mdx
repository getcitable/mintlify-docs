Lists what on the brand is waiting on a person: posts scheduled but not posted, open Action Engine tickets with a due date, and product-page changes waiting for a decision. Each item has its owner (a user id), due date, whether it's overdue, and the link where it gets done.

Use this when:
- You deliver nudges for the team (one message or one calendar block listing everything overdue, never one per item).
- The user asks "what's waiting on me?" or "what's overdue?".

Computed from the source records on every call, so a post marked posted or a ticket closed disappears at once. Dismissed items are left out unless include_dismissed is true.

## Inputs

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `overdue_only` | `boolean` | no | — | Only items past their due date. |
| `owner_user_id` | `integer` | no | — | Only items waiting on this user. |
| `include_dismissed` | `boolean` | no | — | Include items someone dismissed. Default false. |
