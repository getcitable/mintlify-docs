Returns recent Citable-emitted actions for the brand, with their measured outcome deltas where the measurement window has resolved. This is the canonical history of "what did Citable do, and what happened next."

Use this when the user asks:
- "What did Citable do for me last month?"
- "Which actions actually moved citations?"
- "Show me the best-performing content actions."
- "What's still measuring (pending outcomes)?"

Skip when the user wants live recommendations (use get_geo_priorities) or current visibility metrics (use get_topical_authority / get_paid_ads_insights).

Inputs:
- actionType (optional): filter by 'content' / 'outreach' / 'technical' / 'operational' / 'paid'
- outcomeStatus (optional): filter by 'pending' (still measuring) / 'measured' (delta computed) / 'inconclusive' / 'failed' / 'not_sent' (couldn't be carried out, e.g. a channel isn't connected) / 'not_posted' (never posted: no posted URL 30 days on, or the draft failed). not_sent and not_posted are final and never count as results; outcomeReason says why.
- limit (default 20, max 100)

Response: \{ rows: [...], totalReturned, status, meta \}. Each row has id, actionType, actionSubtype, emittedAt, executedAt, postedUrl, outcomeStatus, outcomeReason (for not_sent / not_posted), parentActionId and fanOutRole (hub / spoke), deltaMetrics (when measured), and verdict: the fix's latest verdict, or null before one is computed. verdict = \{ label: 'ahead' | 'not ahead' | 'too early', reason (the counts behind it), tooltip (what it was compared with), method ('question' | 'page'), ruleVersion, computedAt \}. A launched action with neither a posted page nor target questions has verdict \{ label: 'not measurable', reason, tooltip: null, method: null, ruleVersion: null, computedAt: null \}. Quote label, reason and tooltip word for word.
