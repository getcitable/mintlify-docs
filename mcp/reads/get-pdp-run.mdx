Returns one PDP optimization run and its change proposals (diffs, decisions, write status).

Pass run_id OR shopify_product_id (latest run for that SKU). Use after start_pdp_optimization, or when the user asks about a product page's proposed changes.

baseline_snapshot is included on the run — that is the immutable pre-publish state used for revert.

Skip when: no run exists yet (start_pdp_optimization first).

## Inputs

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `run_id` | `integer` | no | — | PDP run id. |
| `shopify_product_id` | `integer` | no | — | Shopify product id — returns the latest run for that SKU. |
