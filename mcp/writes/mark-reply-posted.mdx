Marks a social reply as posted with the live URL. Sets status='published', stamps posted_url + posted_at. Brand resolved from MCP auth context.

Use this when:
- The user has just posted the reply on Reddit/Hacker News/etc. and wants it tracked.
- A user pastes a comment URL after replying manually.

Skip when:
- The reply hasn't been posted yet — use update_reply for status changes that don't carry a URL.
- The user wants to undo "posted" status — call update_reply with status='scheduled' or 'draft'.

The posted_url should be the live comment's own link (https://www.reddit.com/r/\<sub>/comments/\<thread>/comment/\<id>/), not the source thread URL: Check results in the Chrome extension finds the comment by its id. A Reddit share link (https://www.reddit.com/r/\<sub>/s/\<code>, what Share → Copy link often gives) names no comment. It is still saved, and AI-citation tracking still works through the reply's thread, but ask the user to open it and paste the address Reddit opens (it has /comments/ in it).
