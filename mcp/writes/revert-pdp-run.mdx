Rolls every successfully written proposal on a PDP run back to its baseline_snapshot on live Shopify.

Input:
- run_id (required).
- confirm (required, must be true).

Same owner/admin + readiness gates as publish. Proposals that never wrote are left alone.

Skip when: nothing has been published yet, or the user only wants to reject pending proposals (use decide_pdp_proposal).

## Inputs

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `run_id` | `integer` | yes | — | Run whose written changes to roll back. |
| `confirm` | `boolean` | yes | — | Must be true. Required hard confirm for live Shopify writes. |
