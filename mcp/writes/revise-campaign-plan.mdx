Changes a project plan by its project_id (from plan_campaign or get_ae_projects), before or after approval: add lanes (an owned channel by its account_id from get_cell_answers, or any channel kind), redraft a lane by its name, remove lanes, move the goal, or add notes on questions. Once a project has started its goal stays, and an approved plan's tasks follow the change; done tasks are never touched. Lanes you add or redraft need the team's review again. It can also save where the brand is or isn't listed, or something else the user taught you, to the brand's knowledge. This is a WRITE: only call it when the user asked for the change.
